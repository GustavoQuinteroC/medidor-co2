Medidor de CO₂ para salones y oficinas

Un ESP32 con sensor Sensirion SCD41 mide el CO₂ que se acumula al respirar en un cuarto cerrado y avisa con un semáforo cuándo abrir la ventana. Sirve un panel web con las últimas 24 horas y se instala desde el navegador.

Tres colores, una sola decisión: ¿abro o no?

El aire de afuera tiene cerca de 420 ppm de CO₂. En un cuarto cerrado con gente sube cada minuto. Los umbrales son los que se usan con frecuencia para salones y oficinas; se cambian en el código.

< 800 ppmAire bueno

LED verde. No hay que hacer nada.

800 – 1,199Abre una ventana

LED ámbar. Conviene ventilar pronto.

≥ 1,200 ppmVentila ya

LED rojo y tres pitidos, una sola vez por subida. El botón BOOT lo silencia.

Qué hace el firmware

En el aparato

  • Lectura de CO₂, temperatura y humedad cada 5 segundos.
  • Semáforo con histéresis: para bajar de nivel debe quedar 50 ppm debajo del umbral, así el LED no parpadea en el límite.
  • Sigue midiendo sin WiFi: pantalla, LED y alarma no dependen de la red.
  • Calibración forzada a 420 ppm junto a una ventana abierta.

En tu red

  • Portal para elegir el WiFi desde el celular la primera vez.
  • Panel en http://medidor-co2.local con gráfica de 24 horas, sin internet ni servicios externos.
  • API JSON para conectarlo a otro sistema:

Instálalo desde el navegador

Sin instalar programas: el navegador graba el firmware por USB.

  1. Conecta el ESP32 con un cable USB de datos.Algunos cables solo cargan; si no aparece el puerto, prueba otro.
  2. Presiona Instalar y elige el puerto del ESP32.Suele llamarse CP210x o CH340.
  3. Cuando termine, conéctate a la red medidor-co2 desde el celular.Elige tu WiFi y escribe su contraseña.
  4. Abre http://medidor-co2.local.O la IP que muestre tu router para el aparato.

Tu navegador no puede grabar por USB. Usa Chrome o Edge en una computadora de escritorio.

La instalación necesita una página con HTTPS.

También se puede grabar con PlatformIO: pio run -e esp32dev -t upload.

El firmware se compila y su lógica se prueba automáticamente en cada cambio. Aún no se ha probado en un aparato armado.
